- System prompt with a hashed version (`PROMPT_VERSION d2e75a0422c1`), plus markers that fence off untrusted data.

  - the user's prompt is tokenised on the way in and tool results before they reach the model;
  - tool arguments are detokenised before handlers run;
  - a plaintext check runs before every model call;
  - only the final answer is rehydrated.

  - a failed turn that already queued drafts tells the user how many;
  - a handler exception ends as `INTERNAL_ERROR` with one final event and one record, and no exception text.

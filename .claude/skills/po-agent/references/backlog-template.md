# Backlog Item Template

## User Story Format
```
As a [type of user],
I want [some goal],
So that [some reason / business value].
```

## Acceptance Criteria Format
```
Given [context / precondition],
When [action is taken],
Then [expected outcome].
```

## Change Request Format
```
**Change ID:** CR-[number]
**Requested By:** [Name / Team]
**Date:** [YYYY-MM-DD]
**Priority:** High / Medium / Low
**Status:** Pending PO Review / Accepted / Deferred / Rejected

**Summary:** [One sentence description]

**Business Justification:** [Why this change is needed]

**Scope Delta:**
- Added: [New items]
- Modified: [Changed items]
- Removed: [Removed items]

**Effort Estimate:** [T-shirt size or story points]
**Timeline Impact:** [Delta in days/weeks]

**Acceptance Criteria:**
- [ ] Criterion 1
- [ ] Criterion 2
```
